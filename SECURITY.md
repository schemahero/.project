# Security Policy

## Reporting Security Issues

The SchemaHero maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/schemahero/schemahero/security/advisories/new) form.

For more details, see the [SchemaHero security policy](https://github.com/schemahero/schemahero/blob/main/SECURITY.md).
